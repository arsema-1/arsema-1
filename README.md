## 🚀 Featured Projects

### 📊 Attendance & Payroll Management System

A web-based system designed to manage employee attendance, leave requests, payroll information, and salary payment workflows.

- Role-based access for employees, HR officers, and administrators.
- QR-based attendance tracking with optional location verification.
- Payroll management and salary approval workflows.
- Chapa payment integration for salary transfers.

**Technologies:** Next.js, TypeScript, Tailwind CSS, Express.js, PostgreSQL, JWT.

🔗 [View Repository](https://github.com/arsema-1/attendance_management_with_payroll)

### 🎤 Voxity — Singer & Producer Platform

A Flutter mobile application that connects singers with music producers through vocal samples, search, and communication features.

- Singer and producer profiles.
- Vocal sample publishing and discovery.
- Search by musical interests and genres.
- Text and voice communication features.

**Technologies:** Flutter, Dart, Firebase Authentication, Cloud Firestore, Supabase.

🔗 [View Repository](https://github.com/arsema-1/voxity_project)

### 💊 PharmaFinder — Pharmacy Discovery App

A mobile application concept focused on helping users in Addis Ababa find pharmacies that report having their required medicines.

- Search for medicines and discover matching pharmacies.
- View reported availability, estimated prices, and update times.
- Contact pharmacies for confirmation.
- Separate user and pharmacist experiences.

**Technologies:** Flutter, Dart, Appwrite, OpenStreetMap.

### 📦 Asset Management System

A role-based web application for managing organizational assets and their assignment to employees.

- Asset inventory management.
- Asset assignment and tracking.
- Role-based access for administrators and employees.
- Backend API and relational database integration.

**Technologies:** Next.js, TypeScript, Tailwind CSS, Express.js, PostgreSQL, JWT.
